Generic-mode heading markers now take up no space in the editor. Move, select, copy and find text directly across headings, or turn on **Show manuscript markup** to edit the marker characters. The writing toolbar has more space between Font, size and Style. **File → New File** opens a blank tab in the current window.

When a character or recurring element has several names, **Ctrl+Enter**, a left-click on its entry or **Insert at caret** lets you choose which name to insert. Entries with one name insert immediately.
